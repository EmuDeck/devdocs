    OS-Specific Behavior

    Functions marked "Yes" in OS-specific column have different implementations:

    install_emu(): - Linux: Flatpak or AppImage - Windows: exe or 7z extraction - macOS: DMG mount and copy

    create_symlink_crossplatform(): - Linux/macOS: ln -sf - Windows: mklink /J (junction point)

    move_contents_and_link(): - Linux/macOS: Standard symlink - Windows: Junction point (no admin required)

    extract7z_flat(): - Windows: Uses native tar.exe - Linux/macOS: Uses py7zr library or 7z CLI
